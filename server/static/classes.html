My classes

Make a class code, put it on the board, and students hand in the rocket on their screen with just the code and a first name or nickname. No student accounts or emails.

  1. Make a class here and show students its class code.
  2. Students build a rocket in Rocket Builder, then choose ⋯ → Hand in to my class.
  3. They type the code and a first name or nickname. Their rockets show up below.

Privacy: students give only a first name or nickname (the form tells them not to use their full name). We don't store their IP address or any other detail with it. Classes and everything handed in are deleted 180 days after the class is made, or as soon as you delete them. See the terms.
